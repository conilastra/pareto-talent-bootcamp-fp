# Scorecard marketing

Quiz/scorecard structure from Daniel Priestley / ScoreApp ("scorecard marketing") and Dupple, via [[lead-magnet-trends]]. Not taught in the bootcamp; external best practice.

## Structure
1. **5–7 questions** (10 max). A few are qualifiers: revenue, team size, budget, timeline.
2. **Email gate** between the last question and the result.
3. **3–5 result types**, each with its own label, explanation and next step.
4. **Result type = CRM tag**, so nurture emails speak to that founder's problem (see [[ghl-pipeline-and-workflows]]).
5. Optional: a dynamic PDF report built from the answers.

## Applied to Pareto
- Result types mapped to the personas in `03-CUSTOMERS/personas/`.
- Qualifiers decide routing: qualified → booking page, unqualified → thank-you + nurture ([[qualification-criteria]]).
- Questions can draw on competitor clients' pains: inbox volume, hours on admin, tried a VA before ([[competitor-voice-of-customer]]).
