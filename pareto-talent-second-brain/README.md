# Pareto Talent Final Project — Claude Code folder

Everything for the Pareto Talent bootcamp Final Project in one folder: the company second brain (00–09, 99), the full research reports (10), the prompts (11), and the Final Project brief with slides (12). Original PDF/HTML sources are in `08-SOURCES/raw-files/`.

`CLAUDE.md` is the map: Claude Code reads it automatically when you open this folder, so it knows where everything is and the rules (cite sources, quote client language verbatim, never invent numbers).

## Open it in Claude Code
1. Unzip `pareto-talent-fp.zip` somewhere easy, for example your Documents folder.
2. Open a terminal, then: `cd ~/Documents/pareto-talent-fp` and run `claude`.
   (Desktop app: open the Code tab and choose this folder.)
3. Ask anything, for example "Read current-focus and draft three lead magnet ideas for the founder-stuck-in-the-job persona."

It also still works as an Obsidian vault: open the folder in Obsidian to browse the links.
