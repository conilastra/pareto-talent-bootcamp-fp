# Visual identity

**Look:** dark mode. Near-black blue-green background, emerald green as the brand color with soft green glows and green-to-teal gradient text on key words, an amber "ember" accent for small badges, rounded cards (22px radius). The bootcamp decks follow the same look (dark background, white headlines, key phrase in emerald).

## Palette (from the site's CSS)
| Role | Hex | Notes |
|---|---|---|
| Background | `#080D10` | page bg |
| Surface | `#0F151A` / `#141C22` | cards |
| Text | `#F2F6F4` | headings and body |
| Muted text | `#9AA9A2` / `#697871` | secondary copy |
| **Brand green (primary)** | `#10B981` | theme color, buttons, glows (rgba 16,185,129) |
| Green bright | `#34D399` | gradients, highlights |
| Green light | `#6EE7B7` | gradients |
| Accent mint | `#50D3A1` | `--accent`, highlighted words |
| Teal | `#14B8A6` | end of green → teal gradient |
| Ember (secondary accent) | `#E0973F` / `#F2B968` | eyebrow pills, small icons only |
| Lines | white at 7.5% / 14% opacity | borders |

60-30-10 reading: ~60% dark background/surfaces, ~30% light text, ~10% green (ember used sparingly).

## Fonts (Google Fonts)
| Use | Font | Weights |
|---|---|---|
| Headings | **Plus Jakarta Sans** | 700–800, tight letter-spacing (-0.02em) |
| Body | **DM Sans** | 400–600 |
| Display numbers / prices | Hanken Grotesk | 800 |
| Small mono labels | Space Grotesk | 600 |
Pair to use for the lead magnet: Plus Jakarta Sans + DM Sans.
