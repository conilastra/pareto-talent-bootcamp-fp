# Value stacking

Stack **Product** (they don't have it), **System** (they don't know what to do first), **Community** (nobody around them is doing it). "Nobody pays for volume, they pay for obstacles removed." Aim for a 10X offer using real, independently priced items. Pareto's own stack grew from client requests: placement → community → training → equipment, apps, subscriptions ([[right-hand-program]]). Scarcity and urgency must be real: "Neither works twice on the same audience if it turns out to be fake."
