# Pareto Talent Second Brain, Claude Code folder

The company second brain for Pareto Talent: company, offers, customers, frameworks, market and competitors, brand, sources, research reports (10), prompts (11) and the Final Project brief (12, brief only: the project work products live in Google Docs outside this folder). Original PDF/HTML/Excel sources are in `08-SOURCES/raw-files/`.

`CLAUDE.md` is the map: Claude Code reads it automatically when you open this folder, so it knows where everything is and the rules (cite sources, quote client language verbatim, never invent numbers).

## Open it in Claude Code
1. Open a terminal in this folder and run `claude`. (Desktop app: open the Code tab and choose this folder.)
2. Ask anything, for example "Draft three lead magnet ideas for the founder who was burned before, using only client language from the vault."

It also works as an Obsidian vault: open the folder in Obsidian to browse the links.

Sources fed: see `08-SOURCES/_MOC.md`.
