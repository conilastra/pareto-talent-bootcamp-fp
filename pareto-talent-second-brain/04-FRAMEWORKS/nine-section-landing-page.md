# Nine-section landing page

"A landing page is an offer. Every section on it exists to fight one objection."
1. Hero 2. Social proof 3. Problem 4. How it works (3–4 steps) 5. Benefits 6. More social proof 7. The offer 8. Guarantees 9. Final CTA (same action as hero)

Final project minimum (Part 6): Hero, What's inside, Who it's for, Proof with real Pareto numbers, CTA with the form.
"58% never reach the form" — the hero does most of the work ([[hero-section]]). Pareto's own site: ~93% see the hero, ~50% reach the "reasons" section (Clarity, Day 6).
Build: Lovable / GoHighLevel AI Studio / Claude Code + GitHub + Cloudflare Pages (how paretotalent.com runs). First try ≈70%; expect 3–5 iterations.
