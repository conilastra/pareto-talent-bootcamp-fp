# Persona → Pain → Objection → Language

Define personas **by cause, not demographics**. For each: the pain, the objection, and the exact language. "Miss one link… it's decoration." Angles are different entry points into the same pain, giving an "unlimited number of the ads".
Research order: mine your client base first (Fathom sales calls → Claude), then Reddit, YouTube comments, reviews, then the Facebook Ads Library (bulk-analyse ~50 ads).
ICP = "one paragraph, memorized". "Client words, not marketer words. Never invent the phrasing. Extract it." See [[client-language]], [[icp]].
