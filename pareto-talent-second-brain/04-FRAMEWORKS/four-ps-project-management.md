# 4 Ps of project management and SOPs

**Problem → Plan → Progress → Present** (Pyramid Principle). Work Breakdown Structure; watch project creep; budget = hours × rate × 2. ClickUp: Workspace → Spaces → Lists → Tasks → Subtasks; Claude can build a project via the ClickUp connector. Close with three questions (what went well, what didn't, what we learned), then an **SOP**: purpose, scope, definitions, procedure, Loom walkthrough.
