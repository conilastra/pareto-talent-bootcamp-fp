# Two-layer Second Brain

- **Context layer** (static: SOPs, history, offer and pricing, strategy, books/podcasts, call transcripts) + **Action layer** (live connectors: Gmail, Calendar, Slack, Fathom, CRM, Stripe). "Context without action is a filing cabinet nobody updates. Action without context is an assistant with amnesia."
- **4-hop retrieval:** folder → MOC → file → link; frontmatter, wikilinks, CLAUDE.md.
- **Reverse interview** to build it; **librarian, never the shelver**; one brain per company.
- **Access is earned:** Days 1–7 read-only → first 30 days read + write → 30+ days client-facing/financial.
- **Daily extract** (promises, decisions, tasks, sourced) → **Morning Brief** (commitments; blocked; what ships today; context for each meeting).
- **Six ways it breaks:** connected-not-briefed, broken navigation, manual filing, unlinked notes, one brain two audiences, access never revoked. **Retrieval test** with known-answer questions. README so it "survives you".
